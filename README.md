# 精简版文本编辑器（控制台）

这是主项目的一个精简版本：**放弃图形界面，只保留能跑起来的最小程序**。
文本模型仍然是「红黑树索引的块表（Piece Table）」，五条不变量都由程序自检。

本目录下的文件与主项目完全独立，不引用、不依赖主项目的任何代码；
主项目的文件也没有被改动。

## 目录结构

```
simple/
├── TextBuffer.h/.cpp    文本模型：红黑树块表（纯 C++，不依赖任何库）
├── Document.h/.cpp      文件读写（只用 stdio）
├── main.cpp             控制台交互
├── CMakeLists.txt       构建脚本
├── README.md            本文件
└── temp/                与程序本体无关的临时文件与测试（可整个删掉）
    ├── test_buffer.cpp  文本模型的一致性测试
    ├── test_buffer.exe  测试的可执行文件
    ├── sample.txt       测试用的样例文本
    ├── debug/           调试探针源码与可执行文件
    └── out/             测试与探针的输出
```

`temp/` 里的内容删掉不影响程序运行与构建。

## 构建

```bash
g++ -std=c++17 -O2 -o SimpleEditor main.cpp TextBuffer.cpp Document.cpp
```

或用 CMake：

```bash
cmake -S . -B build && cmake --build build
```

## 运行

```bash
./SimpleEditor                # 交互模式
./SimpleEditor 文件路径        # 打开文件后进入交互
./SimpleEditor --script < 脚本 # 从标准输入逐行读命令
```

程序启动时会把控制台输入输出代码页切成 UTF-8，
因此在默认的 GBK 控制台（代码页 936）下中文也能正常显示，不需要先执行 `chcp 65001`；
退出时会还原成原来的代码页，不影响其他程序。
脚本文件带 UTF-8 BOM 也没问题，读命令时会自动去掉。

交互模式下输入 `help` 查看全部命令：

| 命令 | 作用 |
| --- | --- |
| `open <路径>` | 打开文件 |
| `save [路径]` | 保存，带路径即另存为 |
| `new` | 清空并断开文件 |
| `info` | 显示路径、行数、字节数、最长行、块数、树高 |
| `show [起行] [止行]` | 按行显示内容 |
| `line <行号>` | 显示某一行（`\n`、`\t` 会被转义显示） |
| `pos <行>:<列>` | 行列换算成字节下标 |
| `at <字节下标>` | 字节下标换算成行列 |
| `find <文本> [起点]` | 查找 |
| `insert <行>:<列> <文本>` | 插入，`\n` 表示换行 |
| `erase <起点> <终点>` | 删除区间，坐标写法为 `行:列` |
| `replace <起点> <终点> <文本>` | 替换区间 |
| `check` | 校验红黑树不变量与全部统计量 |
| `quit` | 退出 |

例：

```
open sample.txt
show 0 5
insert 0:0 HEAD
pos 1:2
check
save out\saved.txt
quit
```

## 文本模型

### 结构

- **缓冲区**：只读的字符串，文本只往里追加，已有内容永不改动；
- **块（Piece）**：指向某个缓冲区里的一段连续字节区间，记录起始下标、长度、换行数；
- **红黑树**：块按文档顺序组成一棵二叉搜索树，用于按下标二分下降。

每个结点缓存四个统计量，因此定位到第 N 个字节不需要遍历整棵树：

| 字段 | 含义 |
| --- | --- |
| `size` | 左子树的总字节数 |
| `lines` | 左子树的总换行数 |
| `totalSize` | 整棵子树的总字节数 |
| `totalLines` | 整棵子树的总换行数 |

全树共用一个**哨兵结点** `_nil` 表示空子树：它的 `piece.length` 恒为 0，
用它区分「真实结点」与「空」；哨兵自身为黑，充当全部叶子的角色。

### 五条不变量

| 编号 | 内容 | 校验位置 |
| --- | --- | --- |
| 1 | 每个结点非红即黑 | 用 `bool red` 表示，天然满足 |
| 2 | 根结点是黑的 | `checkTree()` |
| 3 | 每个叶子（哨兵）是黑的 | `checkTree()` |
| 4 | 红结点的两个孩子都是黑的 | `checkSubtree()` |
| 5 | 任一点到其所有后代叶子的路径上黑结点数相同 | `checkSubtree()` 返回黑高比较 |

除五条不变量外，`check()` 还会校验：块的字节区间是否落在缓冲区内、
块的换行计数是否与内容一致、父指针是否正确、四个统计量是否与子树实际一致、
以及总字节数 / 总行数 / 块数是否与树吻合。

### 操作

- **插入**：先把落点所在的块按需切开，再把新块插到切点之前；
  新结点插入后沿父链重算统计量，再做插入修正（红黑树插入的三种情况）。
- **删除**：逐块删除区间覆盖到的内容，走红黑树删除（含四种删除修正）。
- **左右旋**：`rotateLeft` / `rotateRight`，旋转后重算被影响的两个结点。

### 复杂度

- 定位与子树统计：`O(log 块数)`
- 单次插入 / 删除：`O(log 块数)` 次结构操作，加一次块内按字节扫描
- 块数上限 512，超过就整体整理成单块，因此块数不会无限增长

## 与主项目的取舍

| 方面 | 主项目 | 本精简版 |
| --- | --- | --- |
| 界面 | Qt 图形界面 | 控制台命令 |
| 平衡结构 | 红黑树（改为顺序块表 + 自动整理） | **红黑树 + 哨兵**，五条不变量显式校验 |
| 块的位置表示 | 行号 + 行内列 + 结束行列 | 只用起始字节下标 + 长度 |
| 视图 | 只渲染可见区域的排版器 | 无 |
| 撤销、编码识别、换行风格 | 有 | 无（换行统一按 LF 处理） |
| 代码规模 | 约 3600 行 | 约 1100 行（模型 700 行 + 交互 400 行） |

## 测试

```bash
cd temp
g++ -std=c++17 -O2 -Wall -Wextra -I.. -o test_buffer test_buffer.cpp ../TextBuffer.cpp
./test_buffer
```

当前结果：**通过 60 项，失败 0 项**。

测试以 `std::string` 为参考模型逐项对拍，覆盖：

- 空缓冲区、多行文本的行列换算、CRLF 归一；
- 100 万字符单行的分块构建、中间插入、头部尾部插入、跨块删除；
- 6 组各 400 步的随机插入 / 删除 / 替换（每步都比对全文并校验树结构）；
- 800 次小块插入触发整理路径；
- 每一步都调用 `check()` 校验五条不变量与全部统计量。
